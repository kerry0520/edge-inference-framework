# 自动发现固定手机的限定验收

旧helper在手机已在线、显式身份可核时，因只认旧IP/忽略无线服务而自动失败。修复共享Adb.select，并让readiness复用该选择器保留原始退出记录；自动候选来自现有USB、已配对无线服务与合法私网IPv4公告，最多8个，实际核型号与稳定硬件身份，禁止任意第一项就算可信。显式选择保留旧契约。

真实新自动选择和独立12模块客户端readiness通过；无serial正式CLI唯一短题通过，19in/4out与旧参考完整signature一致。五模型文件未变，CLI/native/launcher0，11清理原始退出0，worker消失、forward移除、registry owner0。4token仅作回归，日常64未改，不完整回答质量评价。mDNS回退有mock覆盖，本轮手机已在线，未人为断线制造回退。

83项相关测试：82通过、1既有权限skip。公开副本测试另有实际运行记录。发现前7条/后3条及readiness8条有完整原件，CLI启动成功ADB多为参数摘要，不笼统称所有ADB原始退出都已保存。日志、设备标识原件、运行包、模型和程序不公开；公开派生计数不能独立证明设备执行。

本轮不改变native程序或证明性能。ADB服务和配对可用是前提；本机host日志权限原因未定，foreground临时用法见[地址与手机身份](../../docs/Android地址变化与手机身份-20261017.md)，并未修改ACL或研究无线调试关闭原因。
