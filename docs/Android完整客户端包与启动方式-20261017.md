# 完整客户端包与启动方式

这个包把电脑上的聊天代码与已验收的手机程序放在一起，解决启动时还要寻找旧实验目录的问题。模型计算仍在手机上；它不是 APK，也不包含模型、ADB 或工具链。当前适用固定 Mi11 与 Qwen3-0.6B 配置。

## 先理解这三个部分

| 部分 | 收到什么、负责什么 | 放在哪里 |
|---|---|---|
| Python 客户端 | 接收你的文字，连接手机，发送请求，显示流式文字、确认历史并保存记录 | 包内 `scripts/android/` |
| 手机运行程序 | 调用已链接的 MNN：分词、安排 prefill/decode、执行模型、采样并返回文字 | 包内 `runtime/`，运行时部署到手机 |
| 外部环境与模型 | Python 执行客户端；ADB提供通信；模型提供结构、权重和词表 | 电脑另装 Python/ADB，模型预先放在手机 |

例如输入“你好”：客户端把消息送过去，手机程序用模型计算，再把逐段生成的文字送回来。**客户端包解决的是“怎样交付和启动正确程序”，计算原理仍是消息→token→prefill/decode→MNN图执行→算子→采样。** 静态 MNN 库已链接到手机程序中，运行这个包无需再提供 `.a` 文件；重新编译时才需要构建依赖。

## 当前电脑直接试玩

已生成的本地包在项目的 `build/client-bundle-delivery-20261017/交付包 空格`。进入这个目录，在 PowerShell 执行：

```powershell
python -B scripts/android/phone_client_bundle.py inspect --package . --expected-manifest-sha256 452b3384291f17118128bc67f1f977087d8a3945daf70ced82c699a823f9f9bd
python -B scripts/android/phone_chat.py --mode full --stats --prefill-plan-cache --plan-profile runtime/profile.json --adb-path "C:/实际位置/adb.exe"
```

第二条里的 ADB 路径是当前电脑的位置；把包搬到别处时改成那台电脑的实际位置。手机要已配对、模型已准备好且 ADB 可用。省略 `--serial` 会寻找并核对固定手机身份，不依赖曾经的旧 IP；自动发现失败时可提供当前 `--serial IP:连接端口`。

看到“问题>”后提问。默认最多生成64个token，可加 `--max-new-tokens 128`；`/history` 查看已确认历史，`/new` 开新对话，`/exit` 退出。当前包的正式入口是上面的 full/stats/plan-profile 组合，其他历史 KV/query 模式还需要各自的构建资产。

## 怎样重新导出

在项目根目录，对已经验收的运行包执行：

```powershell
python -B scripts/android/phone_client_bundle.py export --plan-profile "build/fresh-runtime-client-20261017/runtime/手机运行包 空格/profile.json" --output "build/我的新客户端包"
```

输出目录必须不存在；失败记录保留，另选新目录。导出结果给出 `manifest_sha256`，应在包外保存，再用新值检查新包，不能一直套用上面的旧值。此命令复制13份 Python 模块和6份运行包文件，另外生成说明及清单；不复制模型、ADB、历史运行记录或工具链。

工具只接收当前登记的三个固定运行包身份。任意新编译产物要先独立验收，不能通过自己写一份清单就获得准入。构建与验收步骤另见[自学与独立演示手册](项目自学与独立演示手册-20261017.md)。

## 检查究竟证明什么

外部保存的 SHA 固定清单，清单再固定各源码与运行文件的大小和 SHA。搬目录后这些内容应相同；正常会话会新建 `results/`，Python 可能产生普通缓存，检查允许这些产物，但不把它们当可信源码。建议始终使用 `python -B`。

这不是作者签名，也不是解释器或已执行字节码的安全保证，更不能证明其他手机适配成功。公开 GitHub 仓库提供代码与说明，未上传这个包含原生程序的本地包，克隆仓库后仍需准备已验资产和外部环境。

本轮实际导出了 fresh 身份并搬到中文、空格路径；其余两个身份有离线测试覆盖，没有在本轮逐个真实导出。工程证据见本轮记录（本地工程档案，不随公开仓库分发）。理解待你反馈：你应能解释为什么只有 Python 文件不能计算模型、只有手机程序也不能自动拥有权重，以及搬路径为何不应改变程序身份。
