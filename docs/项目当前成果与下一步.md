# 项目当前成果与下一步（2026-10-18）

## 一次请求应怎样串起来

电脑Python维护已确认消息并发送请求 → 手机C++worker调用MNN的Llm::response → 模板/Tokenizer得到token → prefill/decode安排模型执行 → Module/Session/Pipeline运行图、Backend提供Execution → CPU算子计算 → 采样与流式字节返回。

应用历史保存问答；KV保存已算上下文；执行计划保存运行安排；mmap缓存保存权重资源。它们的职责不同。构建与候选检查位于请求开始之前，负责让手机确实运行被测程序，不代替模型计算。

这是**同机新目录、明确已有工具和依赖的复现**，不是另一台电脑从零验证。新程序的限定请求回归也不能继承旧产物的完整数值或性能结论。
