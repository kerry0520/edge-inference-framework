# 离线源码构建审查入口

后续已增加[原件根绑定与纯Python重放](构建审查原件与离线重放-20261018.md)：现有审查参数保持不变，成功后额外写 `receipt.json`，绑定15份审查原件。重放在新目录重新核输入和派生结果，不执行LLVM、不编译模型；原审查与重放均不自动接纳候选。旧目录不会被补写或追认为新协议。

本工具把之前保存在单次实验目录里的构建检查整理为可复用CLI，面向同一固定MNN提交、配方和锁文件下的新输出目录与新程序。它不编译、不部署、不运行模型，也不把候选自动纳入正式profile。

## 它检查什么

- prepared与build由调用者提供外部SHA，配方与锁仍固定；不把任意自报成功的记录当可信结果。
- 按固定配方重建规范命令，核配置/编译/链接/归档原始命令和实际退出；不执行记录中的构建命令。
- 核配置身份、关键改源与worker/helper字节；不宣称审计了全部源码树或整个NDK/sysroot。
- 将build.ninja的MNN静态库目标对象、实际.ninja_log对象、compile_commands映射与归档成员按名称及重数交叉核对。对象数量是观察结果，不硬编码某一次的565/101作为通行条件。
- 重新用显式提供并固定SHA的llvm-ar/readelf读取归档与ELF，核AArch64 PIE、Android加载器及允许的系统动态依赖。
- 可选核候选的四资产绑定；原candidate文件保持pending。

“离线”指不连网络或手机，不代表没有本机原生工具进程。正常成功路径运行四条只读命令：ar t、readelf -h/-d/-l，分别保留stdout/stderr/实际退出码。工具SHA固定的是所选文件字节，不自动认证其官方来源。

## 输入与命令

```powershell
python scripts/android/phone_source_build_audit.py --prepared "prepared.json" --expected-prepared-sha256 "外部准备记录SHA" --build "build.json" --expected-build-sha256 "外部构建记录SHA" --llvm-ar "llvm-ar.exe真实路径" --expected-llvm-ar-sha256 "外部工具SHA" --llvm-readelf "llvm-readelf.exe真实路径" --expected-llvm-readelf-sha256 "外部工具SHA" --output "新的审查记录目录"
```

可加`--candidate candidate.json --expected-candidate-sha256 外部候选SHA`。上面是格式示例，占位内容需要替换，不能照抄运行。SHA应来自独立记录或经审定输入，而不是仅从未知文件重算后就认定它可信。

输出目录必须是新的，父目录须已存在且祖先不含链接；不得覆盖、包含或落入受审源码、对象等输入目录。失败保留原件，不resume覆盖。历史prepared记录中的已知构建路径别名会解析为真实文件并记录；直接CLI元数据与工具文件按普通路径核对，别名不能变成执行任意记录命令的入口。

## 输出怎样使用

通过后保存audit.json、derived.json、input-bindings.json及四工具原件；它只是一份构建证据审查结果。进入审查后的失败会保存失败分类和已发生的工具调用；若输出位置不安全或准备记录未通过前置检查，则只返回非零退出和错误文字，不创建结果目录。缺少build receipt不能伪造一份失败receipt，也不能声称compile/link已经实际执行过。

即使报告通过，手机生成结果仍需要另外验证，正式包准入仍由明确审查决定。它不自动提升candidate状态、不重写旧profile，也不证明新电脑全流程复现或稳定提速。

本轮实际正负结果以阶段记录（本地工程原件）为准。框架主线自学请先读[项目自学与独立演示手册](项目自学与独立演示手册-20261017.md)，不必先研究审查字段。

## 本轮验证结果

17项合成单元测试通过（工具均替身）；另用本地已有完整构建执行真正CLI：4条只读LLVM命令均退出0，实际565个目标对象和565个归档成员一致，包含101个Kleidi对象。565/101是这份构建的观察值，不是任意新构建的准入常数。缺失回执的历史目录退出1，分类missing_build_receipt，没有启动LLVM；历史配置失败原件仍保留，不把审查拒绝称为新编译失败。

学习上只需把它放在请求执行之前：源文件经过编译、归档、链接成为手机程序；构建审查核对这条来源链，手机验收再检查程序实际回答。它们回答不同问题，审查通过不会替代模型数值或性能验证。
